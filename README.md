# 🎨 Elamel — Artisanal Ceramics, Bakery Treats & Family Keepsakes

A modern, responsive, and fully accessible web application for **Elamel**, showcasing food-safe DIY ceramic kits, artisanal bakery treats, and personalized family keepsakes.

![Elamel Brand Banner](/public/logowith-text.png)

---

## ✨ Features & Architecture

### 📱 11 Complete Pages & Navigation
- **Home (`#/`)**: Brand hero, 3 subbrand highlight cards, "Why Families Love Elamel" trust grid, and interactive featured carousel.
- **Elamel Colors (`#/colors`)**: Ceramic kits catalog, subcategory filters (Tableware, Decorative, Gifts, Kids), Glaze Studio, and safety guide.
- **Elamel Goodies (`#/goodies`)**: Bakery catalog, dietary filters (Gluten-Free, Nut-Free, Vegan), and Treat Box builder.
- **Moments & Souvenirs (`#/moments-souvenirs`)**: Custom keepsakes catalog, family stories, and live customizer.
- **About Elamel (`#/about`)**: Brand origin story, core values, safety certification protocols, and workshop calendar.
- **Contact & Orders (`#/contact`)**: Inquiry & pre-order form with live validation, character counter, channels, and FAQ accordion.
- **Global Catalog Search (`#/search`)**: Real-time keyword query, price slider, and category tabs.
- **Structured Sitemap (`#/sitemap`)**: Hierarchical clickable index of all pages and tools.
- **Privacy Policy (`#/privacy`)**: Child privacy protection, zero dark patterns, and GDPR compliance.
- **Terms of Service (`#/terms`)**: Craftsmanship, freshness, and satisfaction guarantee terms.
- **Accessibility Statement (`#/accessibility`)**: WCAG 2.2 AA statement, live display controls tester, and keyboard navigation guide.

---

### 🛠️ Interactive Studios & Mini-Apps
1. 🎨 **Interactive Glaze Studio**: 2D pottery painting simulator with kiln gloss finish preview across dinner plates, mugs, vases, and bunny figurines.
2. 🧁 **Family Treat Box Assortment Builder**: 4-pack / 6-pack assortment customizer with real-time dietary profile monitor and allergen aggregator.
3. 💖 **Live Personalisation Studio**: Real-time SVG customizer with custom family names, anniversary dates, font preview, color accents, and live character limit counters.

---

### ♿ Accessibility & Inclusive Design (WCAG 2.2 Level AA)
- **Text Scaling**: Quick scaling between **100%**, **115%**, and **130%**.
- **High Contrast Mode**: 14:1+ luminance ratio mode.
- **Motion Controls**: Reduced motion toggle for sensitive users.
- **Keyboard Navigation**: Focus outlines, skip link, and `Esc` key modal dismiss.
- **ARIA & Semantics**: Live regions for toasts and shopping drawer.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or later
- npm or yarn

### Installation
```bash
# Clone repository
git clone <YOUR_GITHUB_REPO_URL>
cd elamel

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Type check and build bundle
npm run build

# Preview production build locally
npm run preview
```

## 📦 Tech Stack
- **Framework**: React 18

- **Styling**: Vanilla CSS (Tailored HSL Design Tokens, Glassmorphism, Micro-Animations)
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Outfit* & *Plus Jakarta Sans*)
- **Animations**: Canvas Confetti
